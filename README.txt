# Republic of Korea — GitHub Pages

1. ZIP файлыг задлаарай.
2. Доторх `index.html` болон `assets` хавтсыг GitHub repository-ийн үндсэн (root) хэсэгт оруулна.
3. Хуучин `index.html`-ийг шинэ `index.html`-ээр солино.
4. `assets` хавтсыг бүхэлд нь upload хийнэ. Зургийн нэрийг өөрчилж болохгүй.
5. GitHub Pages идэвхтэй бол сайт автоматаар шинэчлэгдэнэ.

Сайт нь гар утас, компьютер дээр тохирон харагдана. Цэс бүр дээр дарахад тусдаа мэдээлэл нээгдэнэ. Хуулийн зургууд дээр дарж томруулж болно.
