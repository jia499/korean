ЗУРГИЙН КОДЫН ЗАСВАР — korean repository

Таны GitHub repository-д зургууд үндсэн хавтас (root) дээр байрлаж байна.
Тиймээс src дотор assets/ гэж бичихгүй.

index.html файлын 629–640-р мөрийн зурагтай хэсгийг доорх кодоор солино.
Энэ нь зөвхөн зургийн HTML хэсэг; CSS/style, бусад мэдээлэл, хөдөлгөөнд хүрэхгүй.
